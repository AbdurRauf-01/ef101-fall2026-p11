# Changelog

Older versions: see the `changelogs/` folder (`v21.md`, `v20.md`, and `v19.md` and earlier on GitHub).

## v22 (14 Nov 2026)

Project layout and test-tooling release. The database schema and every page and route are unchanged. Tests: 293 of 293 pass (292 of 292 when the optional QR-decoder packages are not installed).

### Added
- **Folders.** The code is sorted into three folders; only the launcher scripts, documents and requirement files stay in the project folder:
  - `backend/`: `app.py`, `qr_labels.py`, `test_app.py`
  - `database/`: `inventory.db`, `schema.sql`, `db.py`, `queries.py` (all SQL), `seed.py`, `migrate.py`, and `backups/` (created when needed)
  - `frontend/`: `templates/` and `static/`
- **Test launchers** `run-tests.bat`, `run-tests.command`, `run-tests.sh` (and `python scripts/launcher.py test`). They look in `venv/` for the packages the tests use, warn how many tests would fail or be skipped, and ask **Y/N** before downloading anything. **N** runs the tests with what is installed and says at the end what was left out. Options: `--yes` (install without asking), `--no-install` (never ask).
- `requirements-test.txt`: the optional packages used only by the QR decode check (`numpy`, `zxing-cpp`).
- README table of how many tests depend on each package: Flask 293 (all), segno 10, numpy + a QR decoder 1.
- The project diagram (`docs/project-schema.svg` / `.png`) now shows the three folders, the QR labels and scanner, the test launcher and the optional test packages.

### Fixed
- **Test count in the documents.** The README, TEAM_SPLIT and report said 292 checks. The real total is 293 when a QR decoder (OpenCV or zxing-cpp) is installed and 292 without one, because the QR decode check is skipped silently when no decoder is present. All documents now say both.
- A stray f-string without placeholders in `queries.py` (found by pyflakes).

### Changed
- `backend/app.py` and `backend/test_app.py` add `database/` to Python's search path; Flask is pointed at `frontend/templates` and `frontend/static` (URLs such as `/static/style.css` are unchanged); the docs route reads `docs/` from the project folder.
- `scripts/launcher.py` starts `backend/app.py`, runs `backend/test_app.py` and seeds from `database/`; script reset and in-app backups now go to `database/backups/` (was `backups/`). Messages say `database/backups/`.
- `APP_VERSION` is `22` (sidebar shows v22).
- Commands are now `python backend/app.py`, `python database/seed.py`, `python database/migrate.py` and `python backend/test_app.py`.
- README, TEAM_SPLIT and the report updated for version 22.

### Notes
- Backups made by version 21 stay in `backups/` in the project folder (if you have any); new ones go to `database/backups/`.
- Without `segno` the app still starts (QR pages explain what to install); 9 tests fail and 1 is not run. Without Flask nothing runs. The launchers install both automatically into `venv/`.
